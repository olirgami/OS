Руководство пользователя myshell

Оболочка myshell — это командный интерпретатор, который позволяет пользователю взаимодействовать с операционной системой UNIX. Она предоставляет интерфейс для запуска программ, управления файловой системой и работы с переменными окружения.

ОСНОВНЫЕ КОНЦЕПЦИИ

Программная среда
Каждый процесс в UNIX работает в определенной среде, которая состоит из набора переменных «имя=значение». Они называются переменными окружения. Самые важные из них — это PATH (список папок, где искать программы) и PWD (текущая рабочая директория). Ваша оболочка автоматически устанавливает переменную shell, указывающую на её местоположение, а для всех запускаемых программ добавляет переменную parent.

Перенаправление ввода-вывода
В UNIX программы по умолчанию получают данные с клавиатуры (стандартный ввод) и выводят результат на экран (стандартный вывод). Хотя данная версия myshell ориентирована на базовое исполнение, понимание этой концепции важно: используя специальные символы (например, > или <), пользователь может заставить программу читать данные из файла или записывать результат в файл вместо экрана.

Фоновое выполнение
Обычно оболочка ждет, пока запущенная программа закончит работу, прежде чем снова показать приглашение к вводу. Фоновое выполнение позволяет запустить программу «на заднем плане», чтобы терминал оставался свободным для других команд. В полноценных оболочках это делается добавлением символа & в конце команды.

ИСПОЛЬЗОВАНИЕ ОБОЛОЧКИ

Запуск
Оболочку можно запустить в двух режимах:

    Интерактивный: просто выполните ./myshell. Вы увидите приглашение myshell>, после чего можно вводить команды.

    Пакетный: выполните ./myshell [имя_файла]. Оболочка последовательно выполнит все команды из этого файла и завершит работу.

Внутренние команды
Оболочка поддерживает следующие встроенные функции:

cd [каталог] — Переход в указанную директорию. Если аргумент не указан, выводится путь к текущему каталогу. При переходе обновляется переменная окружения PWD.
clr — Полная очистка экрана терминала.
dir [каталог] — Вывод списка файлов в указанной папке.
environ — Вывод всех текущих переменных среды.
echo [текст] — Вывод текста в терминал. Лишние пробелы и табуляции при выводе сокращаются.
help — Открывает данное руководство.
pause — Приостанавливает работу оболочки. Для возобновления нужно нажать клавишу Enter.
quit — Завершение работы и выход из оболочки.

Запуск внешних программ
Если введенная команда не является встроенной, myshell ищет программу с таким именем в системных папках и запускает её как отдельный (дочерний) процесс. Например, команды ls, ps или mkdir будут работать через механизм создания нового процесса.
